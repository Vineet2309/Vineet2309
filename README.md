### 🚀 Featured Projects

#### 1. [Multi-Agent Resume Tailor & ATS Optimizer](https://github.com/Vineet2309/Multi-Agent-Resume-Optimizer)
*Asynchronous Multi-Agent ATS Optimization System with Bounded Reflection Loops*
- **Architecture & Engineering:** Built an autonomous multi-agent pipeline using **LangGraph** and **FastAPI** featuring parallel document ingestion, skill taxonomy normalization, and STAR-format bullet rewriting.
- **Agentic Critique Loop:** Implemented a bounded reflection loop for iterative critique and refinement via **Groq API**, measurably improving resume-to-job-description alignment scores.
- **Resilient Gateway:** Engineered an **Express.js API Gateway** with Multer memory buffering and rate-limiting (`express-rate-limit`) to defend upstream LLM inference endpoints from traffic spikes.
- **Tech Stack:** `Python` • `FastAPI` • `LangGraph` • `Groq API` • `PyPDF` • `Node.js` • `Express.js`
- **Links:** [Repository](https://github.com/Vineet2309/Multi-Agent-Resume-Optimizer) | [Live Demo / Backend Service](https://github.com/Vineet2309/Multi-Agent-Resume-Optimizer)

#### 2. [TutorAI & Socratic Assignment Reviewer](https://github.com/Vineet2309/TutorAI)
*Intelligent Multi-Model Agent Tutoring Platform with Real-Time Human Escalation*
- **Bounded Adaptive Engine:** Developed a multi-agent tutoring system with a 3-attempt adaptation cap deploying 4 pedagogical strategies (`slow_down`, `reframe`, `new_question`, `jump_ahead`) to avoid passive answers or infinite student loops.
- **Conversational Mastery & CAS Verification:** Evaluates mastery directly through conversational signals and self-corrections without high-anxiety testing, while verifying mathematical transformations using **SymPy CAS**.
- **Human-in-the-Loop Escalation:** Automatically compiles an AI Handoff Package when adaptations are exhausted, alerting live human instructors via **WebSockets** and **WebRTC 2-Way Audio/Video**.
- **Tech Stack:** `FastAPI` • `LangGraph` • `Groq API` • `Python` • `React.js` • `MongoDB` • `WebSockets` • `WebRTC` • `SymPy`
- **Links:** [TutorAI Repo](https://github.com/Vineet2309/TutorAI) | [Assignment Reviewer Repo](https://github.com/Vineet2309/AssignmentReviewerTutor)

#### 3. [SurplusDrop — Exclusive D2C Inventory Marketplace](https://github.com/Vineet2309/SurplusDrop)
*High-Integrity E-Commerce Platform with Real-Time Inventory Synchronization*
- **Direct-to-Consumer Drops:** Direct factory-to-buyer marketplace allowing verified manufacturers to release limited-edition surplus inventory drops directly to consumers.
- **Data Integrity & Security:** Built with **React** and **Supabase**, enforcing strict Row-Level Security (RLS) policies and role-based access control.
- **Atomic Transactions:** Designed automated **PostgreSQL triggers** and atomic RPC transactions to prevent overselling and ensure strict real-time stock synchronization under concurrent traffic.
- **Tech Stack:** `React.js` • `Supabase` • `PostgreSQL` • `Tailwind CSS`
- **Links:** [Repository](https://github.com/Vineet2309/SurplusDrop) | [Live Demo](https://github.com/Vineet2309/SurplusDrop)
